API 设置
接口地址要填到 /chat/completions 结尾。
模型名点「拉取模型列表」直接问服务器要，最靠得住。
报跨域错误（CORS）不是代码坏了，是浏览器不让网页直接连那个服务器。换个支持跨域的中转地址。
Key 不要发给别人，也别填进要公开的网页里。
人设与提示词
人设包 · 点一下就用
点一个会换上对应的人设；如果名字还是「TA」、也还没聊过，名字和开场白会一起设置。
提示词里的 {名字} 会自动替换成上面填的名字。
回复条数
随机控制条数每次发消息前抽一个条数，让 TA 照着分条
回 1 条
回 2 条
回 3 条
回 4 条
不用正好加到 100，按比例算。全填 0 = 不控制。

原理：模型不会掷骰子。是程序在发请求前抽一个 N，写进提示词「这次分 N 条发」，回来后再校准——多了合并、少了在标点处切开。所以是「大致准」。

发图片、文件、语音时不受这里控制，只回一条。

自动朗读 TA 的回复用手机自带的语音念出来，不花 API 费用
1 = 正常。0.9 慢一点，1.2 快一点。
手机里装了哪些语音，这里就列哪些。安卓可以在「系统设置 → 文字转语音」里装中文语音包。
这个页面还不能自己造音色，用的是系统配音。

记忆与上下文
条数越多越容易超模型上下文长度，超了会报错。建议一两百条就压一次。
比如填 20，就是「老的压成摘要，最近 20% 原样留着」。
（暂无摘要）
摘要会塞进系统提示词，所以别让它太长。压缩只用一次 API。
主动消息
开启定时主动消息页面要保持打开（可以放后台），到点 TA 会主动找你
DeepSeek 谷时（便宜时段）：工作日 12:01–13:59、18:01–次日 08:59；周末全天。
手机锁屏后浏览器会暂停计时，这是系统限制，不是坏了。
多个好友时，主动消息只会发给当前打开的那一个。
时间用 24 小时制，比如 21:30。行首加 # 可以临时注释掉一行。
数据管理
导出配置不含聊天记录和 Key，适合发给别人当模板。
完整备份包含所有好友、所有聊天、API Key，别乱发。
导入会覆盖对应内容，导入前建议先备份。

重置全部：删所有好友的消息 + 摘要，保留好友和设置。

报 CORS / 跨域错误
浏览器不许网页直接连某些服务器。换个支持跨域的中转地址。

报 401
Key 填错了，或者余额没了。

报 model not found
模型名写错。点「拉取模型列表」看真名。

报 400 / context length
对话太长了，去「记忆与上下文」压缩一下。

TA 看不见我发的图
有些模型不支持图片输入，程序会自动降级成只显示图片。

按住说话没反应
用本地文件（file://）打开时，很多浏览器不给麦克风权限。放到 https 地址上就能用。

语音识别没出来文字
浏览器识别在国内经常不可用。这时候语音条会照常发出去，只是转不了文字。

朗读没声音
去手机系统设置里装一个中文语音包，再来「语音与朗读」试听。

主动消息没来
页面必须开着。手机锁屏后浏览器会停掉计时。
所有数据只存在你这台设备的浏览器里。
消息只发给你填的那个接口地址，不经任何第三方。
清除浏览器数据 = 全部丢失，记得用「导出」备份。
